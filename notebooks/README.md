# Notebooks — Nāḍī-Q

This directory contains **Jupyter notebooks for exploratory analysis only**.

## Rules

1. **Notebooks are not experiments.** They do not produce citable results.
2. Notebooks may use real or synthetic data for exploration only.
3. Any finding in a notebook that warrants investigation must be converted
   into a proper experiment script in `experiments/` with a config.
4. Notebooks are not required to be reproducible (they often aren't).
5. Notebooks must never be the primary record of a result.
