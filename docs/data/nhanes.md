# NHANES Dataset

## Overview
This document outlines the usage and access requirements for the NHANES dataset within the Nāḍī-Q platform.

## Capabilities
- **Access Mode**: AUTHORIZED_REMOTE
- **Query Supported**: False
- **Bulk Download Supported**: False
- **Local Data Required**: False

## Access Requirements
This dataset requires explicit authorization. **Nāḍī-Q will never automatically download this dataset**. You must obtain credentials and configure them manually.

## Intended Tasks
- Clinical predictive modeling baseline validation.

## Storage Implications
Large dataset. Utilize cloud querying or selective downloading if possible. Do not cache the full dataset locally.
